## 🔴 최우선 과제 — 테스트 서버로 이관

로컬 PC(Windows)에서 실행하는 방식이 너무 번거로워서, 실제 웹에 올려 URL로 바로 접속 가능한 테스트 서버로 이관하는 작업이 **가장 시급함**.

**계획**: Vercel(호스팅) + Neon(PostgreSQL DB)로 배포. 현재 로컬은 SQLite를 쓰는데, 실서버는 원래 스펙상으로도 PostgreSQL을 쓰기로 되어 있었음(schema.prisma 주석 참고).

**진행을 위해 필요한 것 (사용자가 해야 하는 부분, 브라우저에서 클릭만 하면 됨)**:
1. vercel.com 가입(GitHub 계정으로 1클릭 가능) → Settings → Tokens → Create Token → 토큰 값 확보
2. neon.tech 가입(GitHub 계정으로 1클릭 가능) → 프로젝트 생성(기본값) → Connection string(postgresql://로 시작) 확보

이 두 가지(Vercel 토큰 + Neon 커넥션 스트링)를 Claude에게 전달하면, 이후 스키마 전환(sqlite→postgresql), 마이그레이션, 배포까지 전부 Claude가 처리하고 접속 가능한 URL을 전달함. **터미널 작업 없음.**

> 참고: 로컬 PC(Windows)에서 `npm run dev`로 띄우는 방식은 여러 문제(배치파일 한글 인코딩 깨짐, `.env.local`을 prisma CLI가 못 읽는 문제, 포트 중복 점유 등)로 계속 지연되어 이 방식은 폐기하고 실서버 이관으로 방향을 바꿈.

## 프로젝트 개요

- 팩트파인더(www.factfinder.tv) — 기존 다다미디어 CMS를 자체 구축 시스템으로 전면 교체
- 스택: Next.js 14(App Router, monolith) + Prisma ORM + NextAuth(구글 로그인, 개발중엔 테스트 로그인 병행)
- 회원 5등급: 독자 / 후원독자 / 기자 / 논설위원 / 편집장
- 기사 상태: AUTOSAVE(임시저장) → DRAFT(승인대기, 기자만) → PUBLISHED

## 지금까지 구현 완료된 기능

- 기자용 글쓰기 화면(제목/요약/카테고리/키워드/커버이미지/WYSIWYG 본문/형광펜/특수문자/1면톱/자동저장)
- 편집장 승인대기함(승인/반려)
- 관리자 대시보드 + 키워드/특수문자/회원 관리
- 검색 기능(제목/본문/기자이름)
- 댓글(로그인 필요, 본인 또는 편집장만 삭제, 후원독자 왕관뱃지)
- SNS 공유버튼(카카오톡/페이스북/X) + SNS 임베드(유튜브/X/인스타그램)
- 회원 프로필(닉네임/사진 직접 설정)
- 정기후원(구독) — 결제 연동은 PG사 정보 없어 보류, 상태 전환 로직만 구현
- 카드뉴스(다중 이미지 업로드 → 인스타그램 스타일 캐러셀 → zip 다운로드)
- 기사 읽어주기(TTS, 브라우저 내장 Web Speech API)
- 설문/투표 기능(기사에 투표 첨부, 1인 1표, 실시간 결과 %)

## 알려진 문제 / 미해결

- **디자인**: 사용자가 현재 화면 디자인에 불만족 표시("나중에 정리"). 최종 디자인 재작업 필요 — 기능 다 만든 뒤 한번에 정리 예정.
- TTS는 진짜 기자 음성이 아니라 브라우저 기본 음성(성별만 자동매칭). 나중에 실제 TTS API(클로바 등)로 교체 검토.
- 카카오톡 공유 버튼은 앱키 미등록으로 비활성 상태 (카카오 디벨로퍼스에서 발급 필요).
